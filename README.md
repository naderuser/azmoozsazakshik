# 📚 پنل آزمون‌ساز دوره ابتدایی

یک پنل کامل مدیریت آزمون برای معلمان دوره ابتدایی، ساخته شده با **Cloudflare Worker**.

## ✨ قابلیت‌ها

### 👨‍🎓 مدیریت دانش‌آموزان
- ساخت لینک اختصاصی برای هر دانش‌آموز
- مشاهده و مدیریت لینک‌ها
- کپی لینک با یک کلیک

### 📝 طراحی سوالات
- سوالات تشریحی با امکان درج عکس، اشکال هندسی و علائم ریاضی
- سوالات چهارگزینه‌ای
- سوالات صحیح/غلط
- سوالات کوتاه‌پاسخ
- جابجایی و حذف سوالات

### ✅ تصحیح و بازخورد
- تصحیح دستی سوالات
- ثبت نمره (صحیح / غلط / نیمه‌درست)
- نوشتن بازخورد برای هر سوال
- دانلود پاسخنامه به صورت Word

### 📊 جدول‌ساز حرفه‌ای
- ساخت جدول با تعداد دلخواه سطر و ستون
- طراحی RTL برای زبان فارسی
- خروجی اکسل با جدول‌بندی زیبا
- موضوع جدول در بالای هر جدول

### 📷 اسکنر حرفه‌ای (مشابه CamScanner)
- فیلترهای سریع: اصلی، رنگی، خاکستری، سیاه/سفید، سند، بهبود
- تنظیمات دستی: روشنایی، کنتراست، وضوح، اشباع رنگ
- دانلود به صورت PNG یا PDF

### 🗜️ کاهش حجم عکس
- تنظیم کیفیت تصویر (۱۰-۱۰۰٪)
- انتخاب فرمت خروجی (JPEG, PNG, WEBP)
- پشتیبانی از چند عکس همزمان
- حفظ اندازه اصلی تصاویر

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- حساب **Cloudflare Workers** (پلن رایگان کافی است)
- **Wrangler CLI** نصب شده (`npm i -g wrangler`)

### مراحل نصب

1. **کلون کردن پروژه:**
```bash
git clone https://github.com/naderuser/azmoozsazakshik.git
cd azmoozsazakshik
```

2. **ساخت KV Namespace در Cloudflare:**
   - وارد [Cloudflare Dashboard](https://dash.cloudflare.com) شوید
   - به بخش **Workers & Pages** بروید
   - یک Worker جدید بسازید
   - در تنظیمات Worker، یک **KV Namespace** جدید بسازید با نام `EXAM_KV`

3. **تنظیم wrangler.toml:**
```toml
name = "azmoon-worker"
main = "index.js"
compatibility_date = "2024-01-01"

[[kv_namespaces]]
binding = "EXAM_KV"
id = "YOUR_KV_NAMESPACE_ID"
```

4. **Deploy:**
```bash
wrangler deploy
```

## 📖 نحوه استفاده

### ورود معلم
1. به آدرس `/teacher` بروید
2. در اولین ورود، رمز عبور دلخواه وارد کنید
3. رمز ثبت می‌شود و وارد پنل می‌شوید

### ساخت آزمون
1. در تب **دانش‌آموزان**، یک لینک جدید بسازید
2. در تب **طراحی سوالات**، سوالات آزمون را اضافه کنید
3. سوالات را ذخیره کنید

### دانش‌آموز
1. لینک اختصاصی که معلم داده را باز کنید
2. اطلاعات خواسته شده را وارد کنید
3. به سوالات پاسخ دهید
4. آزمون را ثبت کنید

### تصحیح
1. در تب **تصحیح**، پاسخنامه‌ها را مشاهده کنید
2. هر سوال را تصحیح کنید
3. بازخورد بنویسید
4. ثبت تصحیح را بزنید
