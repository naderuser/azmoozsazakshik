# آزمون آنلاین درس هدیه‌های آسمانی

آزمون آنلاین برای **مدرسه شهید علیرضا دادخدایی سنگبند** که روی **Cloudflare Workers** اجرا می‌شود.

## امکانات

- **صفحه دانش‌آموز**: سربرگ آزمون (آزمون نوبت دوم – درس هدیه‌های آسمانی – نام مدرسه) + فرم اطلاعات (نام و نام خانوادگی، نام پدر، کد ملی) و یک **سوال امنیتی** (مثل `۴ + ۵`) قبل از ورود به آزمون.
- **پنل معلم** (رمز پیش‌فرض: `nader0933`):
  - ساخت دانش‌آموز با **UUID و لینک اختصاصی** برای هر نفر (مشکل ثبت‌نشدن اطلاعات حل می‌شود چون هر دانش‌آموز لینک جدا دارد).
  - **طراحی سوال** در چهار نوع: تشریحی، چهارگزینه‌ای، صحیح/غلط، کوتاه‌پاسخ.
  - مشاهده **پاسخنامه هر دانش‌آموز** پس از ثبت.
  - **دانلود Word** برگه آزمون و پاسخنامه‌ها (با سربرگ و جدول‌کشی).

داده‌ها در **Cloudflare KV** ذخیره می‌شوند.

## راه‌اندازی و دیپلوی

### ۱) نصب وابستگی‌ها
```bash
npm install
```

### ۲) ورود به حساب کلودفلر
```bash
npx wrangler login
```

### ۳) ساخت فضای ذخیره‌سازی KV
```bash
npx wrangler kv namespace create EXAM_KV
```
خروجی یک `id` می‌دهد. آن را در فایل `wrangler.toml` جایگزین `REPLACE_WITH_YOUR_KV_NAMESPACE_ID` کنید.

### ۴) (اختیاری) تغییر رمز پنل معلم
رمز در `wrangler.toml` بخش `[vars]` با کلید `TEACHER_PASSWORD` تنظیم می‌شود (پیش‌فرض `nader0933`).
برای امنیت بیشتر می‌توانید آن را به‌صورت secret ذخیره کنید:
```bash
npx wrangler secret put TEACHER_PASSWORD
```

### ۵) اجرای محلی برای تست
```bash
npm run dev
```
سپس به `http://localhost:8787` بروید.

### ۶) انتشار روی کلودفلر
```bash
npm run deploy
```

## نحوه استفاده

1. وارد پنل معلم شوید: `https://<your-worker>.workers.dev/teacher`
2. در تب «طراحی سوالات» سربرگ و سوالات را وارد و ذخیره کنید.
3. در تب «دانش‌آموزان و لینک‌ها» برای هر دانش‌آموز یک لینک بسازید و لینک را برای او بفرستید.
4. دانش‌آموز با لینک اختصاصی وارد می‌شود، اطلاعات و سوال امنیتی را پر می‌کند و به سوالات پاسخ می‌دهد.
5. پاسخنامه در تب «پاسخنامه‌ها» نمایش داده می‌شود و قابل دانلود به‌صورت Word است.

## مسیرها (Routes)

| مسیر | توضیح |
|------|-------|
| `/` | صفحه اصلی |
| `/teacher` | پنل معلم |
| `/s/{uuid}` | صفحه آزمون اختصاصی دانش‌آموز |
| `/api/...` | APIهای داخلی |
